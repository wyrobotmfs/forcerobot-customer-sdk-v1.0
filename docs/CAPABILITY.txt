ForceRobot Customer SDK v1.0.1
================================================

本包仅封装「当前底层二进制已具备、可稳定对外」的能力。
客户只应依赖 include/forcerobot_sdk.h


一、已提供
------------------------
控制：
  - 生命周期 create/start/stop/destroy
  - 使能/下使能/hold/autozero
  - TCP 设置/清除/查询；payload 设置/查询
  - CSP：move_joint / move_tcp / move_tool
  - CSP+摆肘：move_tcp_null / move_tool_null（1440）
  - 多点：停顿 path、连续 blend（joint/tcp）
  - 流式：joint/tcp stream
  - CST：drag / spring / impedance_joint / impedance_tcp
  - CST 增益读写
  - 状态读取、状态订阅、结果回调（tag）
  - 驱动错误码刷新与读取；清错 frs_clear_drive_errors
  - CSV 采集 start/stop/get_path

运动学（离线，不连总线）：
  - FK / 参考角 IK
  - 臂角 measure / range / solve
  - 直线 MOVL 规划、多点 TCP 路径规划
  - 轨迹 count/copy/destroy

工具：
  - tools/runtime_dual（控制台联调）
  - tools/mass_identify（臂重力 152 点辨识，写 mass.json）


二、关键语义
--------------------------------
  1. API 返回 OK = 受理，不等于已启动或已到位
  2. FRS_RESULT_ARRIVED = 指令参考完成，需自行读 measured 判实测到位
  3. 力控前必须 autozero，且 mass.json 有效；autozero 未完成勿发后续策略
  4. 速度/加速度参数必须为有限正数，0/-1 不是默认
  5. 姿态角 deg，姿态角速度 rad/s
  6. 单实例锁 /tmp/force_robot_sdk.lock；不可与 runtime 并行抢总线
  7. EtherCAT 主站 SOEM 1.4 为 GPLv2，再分发需满足许可义务
  8. 关节软限位以 config/parameter.json 为准（本包 j4 下限常为 0°）
  9. 关节 path_blend 折返时过渡加速度约需 ≥ V²/r，否则整表拒绝
 10. hold/disable/clear_drive_errors 不能替代硬件急停
