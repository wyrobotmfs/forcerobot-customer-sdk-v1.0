runtime_dual 终端命令速查（dual，必须带臂号 0/1）
================================================
重要：
格式：<臂号> <命令> ...
示例臂号用 0；测另一臂把 0 改成 1。

---------------------------------------------------------------------------
只读 / 状态（可先做，不使能）
---------------------------------------------------------------------------
  # read 对象仅认（现场确认）：
  #   all / positions / torques / raw / armangle / drive_mode
  0 read all
  0 read positions
  0 read torques
  0 read raw
  0 read armangle
  0 read drive_mode
  # 不要用：read diagnostics（不在 read 对象列表内）

  # get（现场可用，与 read 不同入口）：
  0 get tcp
  0 get payload
  # 限速等参数请查 config/parameter.json，或用 C++ fr_get_parameter
  # 产品版本用 C++：frs_version() / fr_get_version()，终端无 version

---------------------------------------------------------------------------
使能 / 保持 / 下使能 / 退出
---------------------------------------------------------------------------
  0 enable
  0 hold
  0 disable
  0 autozero
  quit                    # 退出程序（通常不带臂号；若拒绝再试 0 quit）

---------------------------------------------------------------------------
工具 / 负载（建议 hold 或未使能时）
---------------------------------------------------------------------------
  0 set tcp <x> <y> <z> <rx> <ry> <rz>     # m, RPY deg
  0 set tcp clear
  0 get tcp
  0 get payload
  # set payload 若终端支持，以现场试错为准；也可用 C++ frs_set_payload

---------------------------------------------------------------------------
位置运动（使能后；速度务必很低）
---------------------------------------------------------------------------
  # joint：必须 7 个目标角；speed/accel 为可选关键字对（现场确认）
  #   <arm> joint q1 q2 q3 q4 q5 q6 q7 [speed V] [accel A]
  0 joint 0 0 0 0 0 0 0
  0 joint 0 0 0 0 0 0 0 speed 5
  0 joint 0 0 0 0 0 0 0 speed 5 accel 20
  # 错误示例：
  #   0 joint 0 0 0 0 0 0 0 15          ← 15 不能当匿名 speed
  #   0 joint 0 0 0 0 0 speed 15        ← 角不足 7 个
  # 安全：先 0 read positions，在当前角上只改 ±3°，不要直接打全 0

  # tcp / tool 语法若拒绝，把报错贴出再改文档
  0 tcp <x> <y> <z> <rx> <ry> <rz> ...
  0 tool <dx> <dy> <dz> <drx> <dry> <drz> ...
  0 hold

---------------------------------------------------------------------------
力控（使能 + autozero 之后）
---------------------------------------------------------------------------
  0 drag
  0 spring
  0 cst_gains <kp1..kp7> <kd1..kd7>
  0 hold

---------------------------------------------------------------------------
诊断 / 采集
---------------------------------------------------------------------------
  0 drive_errors @1          # 若终端接受；否则用 C++ frs_refresh_drive_errors
  0 read drive_mode
  0 read torques
  0 read raw
  # CSV：终端若无对应命令，用 C++ frs_csv_*

---------------------------------------------------------------------------
建议开测顺序（一次只做一步，通过再往下）
---------------------------------------------------------------------------
第1步 只读（不使能）：
  0 read all
  0 read positions
  0 read drive_mode
  0 get tcp
  0 get payload
  1 read positions
  1 read drive_mode

第2步 使能（急停在手）：
  0 enable
  0 read positions
  0 hold
  0 disable

第3步 低速关节（先记下当前7角，只改其中1轴 ±3°）：
  0 enable
  0 read positions
  0 joint q1 q2 q3 q4 q5 q6 q7 speed 5 accel 20
  # 看“已受理/指令完成”，再 0 read positions 核对
  0 disable

第4步 再测臂1；力控放最后（须 autozero）。

把第1步输出贴回，确认后再 enable。
